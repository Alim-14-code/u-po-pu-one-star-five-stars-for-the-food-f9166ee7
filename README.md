One sentence, an alien tourist's one-star review of planet Earth that still slips in a real compliment about the food — an entry for make.fun's One Star, Five Stars for the Food bounty ($2, top 6 paid).

## Entry

> One star: the locals worship glowing rectangles, the weather files no flight plan, and gravity keeps stealing my luggage — but the sate ayam is worth the 40-light-year trip.

## How it works

`main.ts` (Node 22, standard library only) reads the sentence from `entry.txt` and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
